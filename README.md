## Реализация Шаблонов интеграции корпоративных приложений Грегора Хоп, Бобби Вульф

«Сложная система, которая работает, неизменно оказывается развившейся из простой системы, которая работала. ... Сложная система, спроектированная с нуля, никогда не работает, и её нельзя "залатать", чтобы она заработала. Приходится начинать заново, с работающей простой системы.»

Джон Голл (John Gall), «Закон Голла» (Gall's Law).


## Учебная разведка распределённых систем на asyncio.

Цель — не построить production-систему, а увидеть проблемы вживую: как соединять узлы, какие бывают сбои, что сложно, а что нет.

Транспорт и асинхронность — своими руками (по книге «Python Concurrency with asyncio»).
Координация узлов — минимально, чтобы увидеть проблему, а не решить её.

Разведка не обязана заканчиваться крепостью. Она обязана закончиться картой.
