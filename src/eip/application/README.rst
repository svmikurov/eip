Практикум: Простой пример обмена сообщениями
============================================

Интеграционные решения
======================

Запрос-ответ
------------

Request-reply, с.177.

Демонстрирует использование обмена сообщениями (Messaging, с. 87)
для отправки сообщения с запросом (Command Message, с. 169) и
получения сообщения с ответом (Document Message, с. 171).

Дополнительно используем шаблоны каналов:

- Point-to-Point Chanel, с. 131
- Datatype Chanel, с. 139

Публикация-подписка
-------------------

Publish-Subscriber Chanel, с. 134.

Дополнительно используем шаблоны каналов:

- Datatype Chanel, с. 139
