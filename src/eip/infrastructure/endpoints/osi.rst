==================================
OSI (Open Systems Interconnection)
==================================

- Каждый слой решает одну задачу.
- Слой общается только с соседними (сверху и снизу).
- Слой не знает, как устроены другие — только их интерфейс.


Работа с сокетами на уровнях OSI: app_server и app_client
=========================================================

.. list-table::
   :header-rows: 1

   * - №
     - Уровень
     - Что делает
     - Примеры
   * - 7
     - Application
     - Логика приложения, формат данных
     - HTTP, JSON, твой протокол ``{action, value}``
   * - 6
     - Presentation
     - Кодирование/сериализация
     - ``json.dumps``, UTF-8, ``struct.pack``
   * - 5
     - Session
     - Установка/закрытие сессии
     - ``connect()``, ``close()``, ``select()`` цикл
   * - 4
     - Transport
     - Доставка байтов, порты, надёжность
     - TCP (``SOCK_STREAM``), ``send()``/``recv()``
   * - 3
     - Network
     - Адресация, маршрутизация
     - IP (``AF_INET``), ``(host, port)``
   * - 2
     - Data Link
     - Кадры, MAC
     - NIC, драйвер
   * - 1
     - Physical
     - Битstream по проводу
     - кабель, Wi-Fi


7 уровней (сверху вниз — как видит пользователь)
================================================

.. list-table::
   :header-rows: 1

   * - №
     - Название
     - Задача простыми словами
     - Примеры
   * - 7
     - Application (Прикладной)
     - То, что делает программа: HTTP, JSON, поиск, отправка сообщения
     - HTTP, FTP, SMTP, DNS, твой ``action='search'``
   * - 6
     - Presentation (Представления)
     - Как данные закодированы: UTF-8, JSON, шифрование, сжатие
     - ``json.dumps``, ``.encode('utf-8')``, TLS, JPEG
   * - 5
     - Session (Сеансовый)
     - Установка, поддержание и закрытие «разговора» между двумя сторонами
     - ``connect()``, ``close()``, сессии, ``selectors``
   * - 4
     - Transport (Транспортный)
     - Доставка данных целиком и по порядку, порты, надёжность
     - TCP, UDP, ``send()``, ``recv()``
   * - 3
     - Network (Сетевой)
     - Адресация и маршрутизация между сетями (IP-адреса)
     - IP, ICMP, роутеры, ``AF_INET``
   * - 2
     - Data Link (Канальный)
     - Передача между соседними устройствами в одной сети (MAC-адреса)
     - Ethernet, Wi-Fi, коммутаторы
   * - 1
     - Physical (Физический)
     - Биты по проводу/воздуху/оптоволокну
     - кабель, разъём, радиоволны


Инкапсуляция: как данные «заворачиваются»
=========================================

.. code-block:: text

   [Application data]                                       ← сообщение
      ↓ Presentation: кодируем в UTF-8/JSON
   [Application data]                                       ← те же байты, но формат определён
      ↓ Transport: TCP добавляет заголовок (порты, номер сегмента)
   [TCP header][Application data]                           ← сегмент
      ↓ Network: IP добавляет заголовок (IP-адреса)
   [IP header][TCP header][Application data]                ← пакет
      ↓ Data Link: Ethernet добавляет заголовок (MAC-адреса) и трейлер
   [Eth header][IP header][TCP header][data][Eth trailer]   ← кадр
      ↓ Physical: превращаем в биты
   0101101010...
